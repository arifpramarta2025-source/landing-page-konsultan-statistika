# Landing page — Mohamad Arif Pramarta, S.Stat.

Situs statis jasa konsultasi statistika & analisis kebijakan, workshop AI/Excel/analisis data, serta privat & mentoring.

Isi repo ini adalah paket publikasi yang dihasilkan `build-publication.cjs` dari folder kerja lokal. Ubah sumbernya di folder kerja, lalu bangun ulang paket dan perbarui repo ini.

## Deploy (Cloudflare Pages)
- Framework preset: **None**. Build command: kosong. Output directory: `/`.
- Paket ini masih versi pratinjau (`noindex`). Setelah domain final ditentukan, bangun ulang dengan `node build-publication.cjs https://domain-final/` agar canonical, og:url, sitemap, dan izin indeks terpasang.
- Setelah live: kirim formulir sekali, lalu klik tautan konfirmasi FormSubmit di email agar formulir aktif.
- Aktifkan Cloudflare Web Analytics (tanpa cookie) agar sesuai dengan Kebijakan Privasi.
